# Contributing / 参与贡献

Contributions that improve the end-to-end method, accessibility, chart-selection guidance, story delivery, or finished-image gallery are welcome.

欢迎提交能够改进端到端方法、无障碍设计、图表选择、故事交付或成品图片画廊的贡献。

## Workflow / 流程

1. Fork the repository and create a focused branch.
2. Keep the Skill software-agnostic and preserve the complete communication chain; do not turn it into a chart cookbook.
3. If adding a gallery example, contribute a polished final PNG and a short explanation in the pull request.
4. Validate the Skill structure and inspect README links before submitting.
5. Open a pull request explaining the communication problem and why the change improves the result.

1. Fork 本仓库并创建目标明确的分支。
2. 保持 Skill 与具体软件无关，并保留完整沟通链；不要把它拆成图表工具箱。
3. 新增画廊示例时，只需提交经过完善的最终 PNG，并在 Pull Request 中简要说明图表用途。
4. 提交前验证 Skill 结构并检查 README 链接。
5. 提交 Pull Request，说明数据沟通问题以及修改带来的改进。

提交贡献即表示你同意以 MIT License 发布该贡献。
